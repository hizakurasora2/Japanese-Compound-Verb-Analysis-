# 🔬 chiVeを使った日本語複合動詞の計量的分析
### Semantic Analysis of Japanese Compound Verbs with chiVe



---

## 📌 研究のポイント

- 🎯 **研究対象**：「走り回る」「書き込む」など、二つの動詞を組み合わせた**複合動詞**
- ❓ **問い**：
1. 日本語複合動詞の意味は前項動詞と後項動詞の意味に比べて、どのような傾向があるか？
2. 埋め込み表現で捉えた日本語複合動詞の意味特徴が学習者にどう役立つか？

- 💡 **アプローチ**：大規模コーパス × Python × 統計分析で**客観的な数値**として解明

---

## 🛠️ 使用ツール・手法

| ツール | 用途 |
|---|---|
| **Python 3.x** | データ処理・分析の中心 |

## 💡 学習支援への応用

埋め込み表現による複合動詞の意味分析は、日本語教育において以下の2点で貢献します。

1. **学習方針の数値化（主要部スコアの活用）**
   - **注目すべき動詞の可視化**: 「前項（V1）優位」か「後項（V2）優位」かをスコアで提示。
   - **学習方略の精緻化**: 学習者がどちらの構成要素に着目して意味を推測・理解すべきかを明確にガイド可能。

2. **習得困難語の客観的な特定（類似度による4分類）**
   - **データ駆動型の語彙選定**: 教師の経験則や直感に頼らず、構成要素との類似度からイディオム的（非構成的）な難関語を特定。
   - **指導優先度リストの作成**: 「頻度」×「類似度」を掛け合わせ、優先的に指導すべき語彙リスト（表5）を客観的に抽出。

## ⚠️ 本研究の限界と今後の課題

- **静的埋め込みモデル（chiVe）による多義性の丸め込み**
  - 文脈に依存しない単一ベクトルを用いるため、多義語（例: 「塗り替える」の字義的用法と比喩的用法）の意味が平均化され、分析精度に影響している可能性がある。
  - *今後の課題*: 文脈付き埋め込み（BERT等）を活用した語義別の分析検討。

- **学習者の実際の習得難易度との整合性**
  - 分散表現モデル上の意味的中心性（主要部スコア・4分類）が、学習者の心理的処理や実際の習得負担と一致するかは本研究のみでは検証できていない。
  - *今後の課題*: 第二言語習得（SLA）研究と連携した、学習者対象の実証的検証。
